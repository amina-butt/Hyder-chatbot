Hyder Assistant — Widget Test Page

This page embeds the standalone chat widget. Click the bubble in the bottom-right corner to open the chat window.

The widget streams responses from http://localhost:8000/api/chat/stream — make sure your FastAPI backend is running locally and accepts a JSON body of the shape { "session_id": "...", "message": "..." }, responding with a streamed text body.

Try sending both English and Urdu / Roman Urdu messages to see the automatic RTL/LTR text alignment in action.
